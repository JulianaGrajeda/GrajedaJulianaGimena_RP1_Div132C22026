--------------------------------------------------
                    TABLA
--------------------------------------------------

    Orden mental:
    1. Seleccionar contenedor.
    2. Vaciarlo.
    3. Comprobar si hay datos.
    4. Crear tabla y cabecera.

        const tabla = document.createElement("table");
        const cabecera = document.createElement("thead");

        cabecera.innerHTML = `
            <tr>
                <th></th>
                <th></th>
                <th></th>
            </tr>
        `;

        tabla.appendChild(cabecera);

    5. Recorrer la lista con forEach.
    6. Crear filas y agregarlas al cuerpo.

        lista.forEach((item) => {
            const fila = document.createElement("tr");

            fila.innerHTML = `
                <td></td>
                <td></td>
                <td></td>
            `;

            cuerpo.appendChild(fila);
        });

    7. Agregar tabla al contenedor.

        tabla.appendChild(cuerpo);
        contenedor.appendChild(tabla);
